Kebijakan Privasi — PAKEET! : Kurir Simulator

Developer: Clearframe Studio · Berlaku sejak: 24 November 2026 · English version below.

Kebijakan ini menjelaskan data apa yang dipakai oleh game PAKEET! : Kurir Simulator ("Game") untuk Android.

1. Data yang kami kumpulkan

Clearframe Studio tidak mengumpulkan, menyimpan, atau menjual data pribadi kamu. Game tidak punya akun, login, chat, atau fitur sosial. Progres permainan (koin, upgrade, pengaturan) disimpan hanya di perangkat kamu dan terhapus saat Game di-uninstall.

2. Iklan (Google AdMob)

Game menampilkan iklan melalui Google AdMob, termasuk iklan berhadiah yang hanya diputar bila kamu memilihnya. AdMob dapat mengumpulkan dan memproses data berikut untuk menampilkan iklan, mengukur iklan, dan mencegah penipuan:

  • ID Iklan perangkat (Advertising ID / AAID)
  • Alamat IP dan perkiraan lokasi kasar dari IP
  • Informasi perangkat (model, versi OS, bahasa) dan interaksi dengan iklan
  • Data diagnostik dan crash dari SDK iklan

Data ini diproses oleh Google sesuai Kebijakan Privasi Google dan cara Google menggunakan data dari aplikasi partner. Di wilayah yang mewajibkan persetujuan (misalnya EEA/UK), Game menampilkan formulir persetujuan Google (UMP) dan pilihan privasi bisa diubah kapan saja lewat tombol Privasi di menu utama.

Kamu bisa mereset atau menonaktifkan personalisasi iklan di Pengaturan Android > Google > Iklan.

3. Anak-anak

Game ditujukan untuk pengguna berusia 13 tahun ke atas dan tidak sengaja mengumpulkan data pribadi anak di bawah 13 tahun.

4. Keamanan

Komunikasi SDK iklan dengan server Google dienkripsi (HTTPS). Data simpanan Game tidak dikirim ke server mana pun.

5. Penghapusan data

Karena tidak ada akun dan data progres hanya ada di perangkat, kamu bisa menghapus seluruh data dengan menghapus data aplikasi atau meng-uninstall Game. Untuk data iklan, gunakan pengaturan ID Iklan Android.

6. Perubahan

Kebijakan ini dapat diperbarui. Versi terbaru selalu ada di halaman ini.

Privacy Policy — PAKEET! : Kurir Simulator

Clearframe Studio does not collect, store or sell your personal data. The game has no accounts, login, chat or social features. Game progress is stored only on your device and is removed when you uninstall the game.

Ads. The game shows ads through Google AdMob, including rewarded ads you choose to watch. AdMob may collect the device Advertising ID, IP address and approximate location derived from it, device information, ad interactions, and diagnostic data, to serve and measure ads and prevent fraud, under the Google Privacy Policy. Where consent is required (e.g. EEA/UK) the game shows Google's consent form (UMP); you can change your choice any time from the Privacy button in the main menu.

Children. The game is intended for users aged 13 and over.

Deletion. Clear the app's data or uninstall the game to delete all game data. Reset your Advertising ID in Android settings.
